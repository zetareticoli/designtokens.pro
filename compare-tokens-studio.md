# Design Tokens Pro vs Tokens Studio

[Tokens Studio for Figma](https://docs.tokens.studio/) is the plugin many teams use to author design tokens as JSON without writing JSON by hand. You create colors, spacing, typography, shadows, and more; reference tokens; switch sets for themes; sync to GitHub; and push styles or Figma Variables. The official docs are a product manual: token types, sets, themes, export, Git sync, DTCG vs legacy format.

That is necessary. It is not a substitute for deciding what your system should be called and how it should be layered.

## The plugin solves authoring

Tokens Studio is strong when designers need a no-code editor that still emits files engineers can transform (often with Style Dictionary and `@tokens-studio/sd-transforms`). If your bottleneck is maintaining tokens in Figma and in Git at the same time, the plugin is the right class of tool.

## The guide solves the model

Design Tokens Pro does not compete with a plugin license. It is a $39 written guide on the decisions you will click into Tokens Studio either way:

- Which elements belong in a token name
- How taxonomy becomes a convention the whole team can follow
- When to use primitive, semantic, and component tokens
- How compound tokens differ from single values
- How to structure themes and color modes
- How to document tokens and take them through a lifecycle

A powerful plugin with an unclear taxonomy still produces a powerful mess.

| | Design Tokens Pro | Tokens Studio |
|---|---|---|
| What it is | Self-paced written guide | Figma plugin + documentation |
| Cost | $39, lifetime access | Free core; Pro for advanced features |
| Output | Understanding, examples, PDF | JSON, styles, variables, Git sync |
| Depends on Figma? | No | Yes |

You can — and often should — use both.

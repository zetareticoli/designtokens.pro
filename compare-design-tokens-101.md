# Design Tokens Pro vs Design Tokens 101

[Design Tokens 101](https://www.udemy.com/course/design-tokens-101/) is Osama ElDrieny’s beginner course on Udemy: six sections, 16 lectures, about one hour and nine minutes. Useful first pass. Not a substitute for a full guide on architecture, themes, and process.

## What each one is

**Design Tokens 101** is an introductory video: why tokens exist, how they differ from variables, a tools survey, fundamentals, naming and structure (including token levels), plus a short look at implementation. A Figma Community tasks file sits alongside it. Often free or low-cost on Udemy.

**Design Tokens Pro** is a written digital guide: eight chapters, 100+ pages, online + PDF, $39. Foundations, token name elements, three-tier architecture, taxonomy, compound tokens, themes and color modes, lifecycle, and documentation — with JSON examples.

| | Design Tokens Pro | Design Tokens 101 |
|---|---|---|
| Format | Written guide (online + PDF) | Short Udemy video + Figma tasks |
| Length | Eight chapters, 100+ pages | ~1 hour 9 minutes, 16 lectures |
| Price | $39 (30-day refund) | Often free or low-cost on Udemy |
| Depth | Architecture, compound tokens, themes, lifecycle, docs | Orientation: what tokens are, naming basics, tools overview |
| Best when | A reference to build and run a token system | A first hour of context |

## Where Design Tokens 101 is stronger

Start there if you have never used the word “token” and you prefer video. One hour is the right size for orientation.

## Where the guide is stronger

After the intro, you still need taxonomy, name structure, token tiers, compound values, themes, lifecycle, and documentation. Design Tokens Pro is the document you keep open while you make those decisions.

Watch 101 for orientation. Buy Design Tokens Pro when you are ready to name, layer, and ship a real set.
